# Défense de Bourg Palette

Un tower defense Pokémon jouable directement dans le navigateur.

## ▶ Jouer

**https://kyfudy.github.io/Pok-d-fense/**

## Contenu

- **Aventure** : 8 lieux de Kanto, 15 chapitres chacun, 4 difficultés
- **Infini** : des vagues sans fin sur les 8 lieux
- **Monotype d’Évolution** : farme les fragments des 15 Méga-Évolutions
- **Raid de boss** : un boss géant, un maximum de dégâts en 3 minutes
- **Cauchemar** : le mode extrême, avec 48 Pokémon Oniriques à capturer
- Invocations, machine à traits, améliorations, plateformes aériennes…

La sauvegarde se fait automatiquement dans ton navigateur.
